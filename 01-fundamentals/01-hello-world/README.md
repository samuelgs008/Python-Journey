# 01 - Hello World

Welcome to your first problem! Write a program that prints the message **Hello World!**

## Input

There is no input for this problem.

## Output

Print the message `Hello World!` followed by a line break.

<details>
<summary>💡 Hints (try on your own first!)</summary>

1. The function that shows text on the screen is `print()`.
2. Text goes between quotes: `"like this"`.

</details>

## ⚡ Challenge

Already solved it? Now try again: print `Hello World!` **three times**, one per line, using a single `print()` and writing the text `Hello World!` only once.

### Input

There is no input for this problem.

### Output

Print `Hello World!` three times, one per line, with **no blank line** at the end.

### Sample

<table>
<tr><th>Sample Input</th><th>Sample Output</th></tr>
<tr>
<td><pre>
(no input)
</pre></td>
<td><pre>
Hello World!
Hello World!
Hello World!
</pre></td>
</tr>
</table>

<details>
<summary>💡 Hints</summary>

1. Try `"ab" * 3` in the terminal. And remember that `"\n"` is a line break inside text.
2. `print()` adds a line break at the end by itself. The `end` parameter changes that: `print("hi", end="")`.

</details>
